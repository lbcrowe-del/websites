You've had your license for a few days — here are the things most people find helpful when they're getting started.

👥 Map your users first

Before running a migration, use the User Mapping screen to match source accounts to destination accounts. ServerBridge will automatically re-permission migrated files so nothing lands in the wrong inbox.

📊 Run a test migration first

Pick a single non-critical folder and migrate it to a test destination before you commit to the full run. This is the fastest way to catch permission or connectivity issues before they affect real data.

⏰ Schedule it for off-hours

Large migrations are best run overnight or over a weekend. ServerBridge can be left running unattended — it'll handle transient network errors automatically and pick up where it left off if interrupted.
