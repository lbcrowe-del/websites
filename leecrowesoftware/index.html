About

Lee Crowe Software is an independent studio run by Lee Crowe. It started with the unglamorous, high-stakes work IT teams do every day: migrations, cleanups and cutovers. It has grown into building whatever is worth building, from IT tools to consumer apps.

The approach stays the same whatever the project. Understand the actual problem, build the simplest thing that solves it properly, and make it reliable enough that you stop thinking about it.
